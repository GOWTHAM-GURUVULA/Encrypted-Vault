# Privacy Policy for Encrypted Vault

Effective date: March 31, 2026

Encrypted Vault is a Windows desktop app designed to protect files locally on a user's device.

## Data the app stores locally

Encrypted Vault may store the following data on the local device:

- encrypted vault data
- temporary unlocked vault contents while the vault is open
- file names and original restore paths used for restore functionality
- category metadata for vault items
- recovery-key status and related vault metadata

## Data the app does not collect

Encrypted Vault does not operate a cloud vault service and does not intentionally upload the user's files to the developer.

The app does not sell personal data, rent personal data, or share vault contents with third parties.

## Passwords and recovery keys

Passwords and recovery keys are used locally to protect access to the vault.

The developer does not receive, store, or recover the user's password or recovery key. If both are lost, encrypted data may become permanently inaccessible.

## Local storage behavior

When the vault is locked, the user's data is stored as encrypted vault data on the local device.

When the vault is unlocked, the app may temporarily create working files in the local application data folder so the user can view, restore, or manage vault contents.

Depending on the current vault workflow, adding a file may move that file into secure vault storage until it is restored.

## Internet access and hosted promos

Encrypted Vault can optionally show the developer's own hosted promo or update cards when the device is online and a promo feed URL has been configured.

These promos are not required for vault functionality. If no promo feed is configured, or if the device is offline, the promo panel is not shown.

If a hosted promo feed is used, that external host may receive basic HTTPS request metadata such as IP address, user agent, and standard web request details.

## Security

Encrypted Vault is intended to protect local files using encryption and controlled local access. No software can guarantee absolute security, and users are responsible for safeguarding their devices, passwords, and recovery keys.

## Children's privacy

Encrypted Vault is not directed to children under 13 and is not intended to knowingly collect personal data from children.

## Changes to this policy

This policy may be updated as the app evolves. The latest version should be published with the app repository, app listing, or official distribution page.
